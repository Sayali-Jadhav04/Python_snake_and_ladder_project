# Python_snake_and_ladder_project
This is a Snake and Ladder game developed as a project. Players roll a dice and move across the board.
Landing on a ladder moves the player up, while landing on a snake moves the player down. The first player to reach the final square wins the game.

Features:-
1. Two-player gameplay
2. Random dice rolling
3. Snakes and ladders functionality
4. Win detection
5. User-friendly interface

Technology used is Python.

Learning Outcomes

This project helped me understand:

1. Programming fundamentals
2. Conditional statements
3. Loops
4. Random number generation
5. Game logic implementation
